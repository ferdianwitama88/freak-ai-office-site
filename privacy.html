Privacy Policy

Effective November 3, 2026

1. Scope

This policy describes the Freak AI Office information website and the private creator dashboard currently being developed. The public website is informational and has no TikTok login or posting functionality.

2. Information handled

The information website does not request your TikTok username, password, or access token. GitHub Pages, which hosts the information website, may process technical access information under GitHub's own privacy practices. The private dashboard stores creator-submitted job titles, draft content, review decisions, and manually recorded costs and revenues in a local database on the owner's device.

If the planned TikTok OAuth integration is enabled in a future release, it will request only the permissions shown during TikTok authorization, which may include basic profile information and video upload/publishing permissions. This functionality is not yet deployed. This policy will be updated before any live OAuth data collection begins.

3. Purpose

Information is used to organize, create, and review short-form content. Planned TikTok authorization, if implemented and approved, would be used only to connect the authorized account and initiate account-owner-approved upload or publishing actions.

4. Storage and sharing

The current dashboard keeps work records locally on the account owner's machine. The public website does not expose the dashboard database or TikTok credentials. Any future third-party integration will be disclosed before it is enabled. No personal data is sold through this website.

5. Security

Access to the private dashboard is protected by an authentication token and a private connection. No internet-connected system can be guaranteed completely secure; owners should protect device access and secrets.

6. Retention and deletion

Locally stored work records remain on the owner's device until the owner removes them or the application provides a deletion mechanism. No automated deletion schedule is currently promised. If a TikTok connection becomes available, the owner will be able to revoke authorization through TikTok account settings; any locally stored OAuth credentials will also need to be removed through an implemented disconnect or deletion procedure.

7. Contact and requests

For non-sensitive questions, use the public project issue tracker. Never include passwords, tokens, private account identifiers, or sensitive personal details in public issues. A private contact mechanism for individual data-rights requests will be published before third-party account data is collected.

8. Changes

This policy may be updated as features and data-processing practices change. The effective date will be revised when material changes occur.
